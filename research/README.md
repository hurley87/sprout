# Sprout — Product and Curriculum Notes

**Working concept:** short, playful learning experiences where children participate through conversation and see their choices affect an illustrated scene.

**Status:** product exploration and authored curriculum proposal. Updated **2026-11-03**. No learning effectiveness or age suitability has yet been established by these documents.

The current direction is broader than mathematics, with optional characters and a shared catalog for girls and boys. The child chooses an appealing activity; the parent can understand the skills it exercises. Voice-only child gameplay without reading remains the starting interaction constraint.

## Decisions and hypotheses

| Topic | Current status |
| --- | --- |
| Broader learning experiences | User direction: do not limit the product to math |
| Characters | Optional; not a prerequisite for an activity |
| Audience | Shared catalog for girls and boys |
| Initial age range | Proposed ages 3–6, centered on 4–5; initial supervised trials include ages 3–5 and some six-year-olds |
| Ages 7–11 | Possible later expansion requiring additional research and design |
| Initial duration | Proposed 3–5 minute core for the three worked pilot experiences; optional extension and early ending |
| Navigation | Small choice of eligible experiences proposed; subject filters remain possible. This does not establish a finalized replacement for the older subject-first home screen |
| Parent involvement | Supervised early trials; independent use after setup remains a goal to validate |
| Learning state | Authored application logic owns progression; AI handles bounded conversational realization |

The age range, duration, sample size, and progression heuristics are design hypotheses, not research-derived thresholds.
