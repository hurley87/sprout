# Halloween artwork

Original illustrations supplied by the project owner for #87. The transparent PNGs depict a bat, pumpkin, lantern, and ghost. The JPEGs depict a moonlit porch and a festive party yard.

Every counting scene uses the porch. It contains a jack-o'-lantern by the steps, small pumpkin lights in the tree and a porch lamp, so counted pumpkins and lanterns sit in the open middle and the tutor brief names those decorations as not part of the count.
