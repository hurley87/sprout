# Require parent-reviewed evidence for future lessons

In a one-child prototype, a mistaken observation can influence every later lesson and make apparent personalization rest on a false premise. Only observations accepted or corrected by the parent may enter Sprout's learning profile; live voice decisions and post-session Observer proposals cannot approve their own conclusions. We accept the daily review cost to keep future lesson choices grounded while separately measuring the Observer's uncorrected output.

## Consequences

- Store original proposals, parent decisions, and corrected observations separately, with links to the supporting exchange.
- Keep pending and rejected proposals out of planner inputs.
- Generate the next daily plan after review, using identifiable reviewed evidence; regenerate an undelivered plan if its source review changes.
- Preserve originals when calculating acceptance, so parent repair cannot make the Observer appear more accurate.
- The resulting experiment validates a parent-reviewed learning loop. Removing this boundary requires an explicit new decision and evidence that autonomous updates are trustworthy.
